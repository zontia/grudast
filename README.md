# gruda.hr

Statična stranica GRUDA d.o.o. — beton, zidni paneli, peleti i drva za ogrjev (Turjaci, Split i okolica).

Dizajn v4 "Noćna smjena". Ne uređuje se ručno: generira se iz `Desktop/gruda/gen.py` (`python gen.py v4`),
a sadržaj foldera `site/` je ovaj repozitorij. Fontovi (Barlow, OFL) i GSAP su na samoj stranici.
